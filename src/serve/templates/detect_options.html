Detection method

Three methods are available per run and produce the same evidence tables — they differ in where the data comes from and what they cost. The API method stays the default; local clone and hybrid are additive, not replacements.

Trace pack

The immutable pattern set used for matching. Packs are independent: each one carries its own agents and supports its own channels, and the lists below show only what the selected pack can detect. Every stored evidence row carries this version.

Agents ({{ agents | length }})

The selected pack’s roster. Only the selected agents are matched, counted, and exported; keeping all checked scans for every agent the pack knows. Selection narrows matching, not fetching — the same API calls run either way. Agents marked legacy are matched only through historical evidence.
