i

“How much of this repo’s recent work was written with a coding agent?” For each repo we look at the latest {{ detection.windows.commits }} commits on its default branch, and count a commit as agent-assisted when its author, its message (an agent co-author or signature line), or the pull request behind it points to a detected agent.

Example: a repo where 12 of its counted commits are flagged shows 12%. The number on this card pools every repo in the run — all flagged commits ÷ all counted commits — so repos with more commits count more; it is not the average of the per-repo percentages.

Housekeeping commits (merges, reverts, version bumps) and CI bots are skipped on both sides, and only the latest {{ detection.windows.commits }} commits are seen: older history and quietly-used agents stay invisible, so treat this as a conservative lower bound.

Levels used by the papers: experimental <1% · limited 1–5% · consistent 5–20% · pervasive >20%.
