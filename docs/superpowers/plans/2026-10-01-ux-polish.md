# UX Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add strictly optional UI affordances to the gitcorpus console — busy feedback, actionable clone errors, localStorage recent filters, guided empty states, keyboard-help discoverability, copy-link sharing, clone cancellation, modal focus management, and sticky run-table headers — without changing any existing control, flow, result, or byte-exact JSON response.

**Architecture:** All changes are additive DOM/CSS/JS layered onto the existing Jinja2 + htmx 2.0.4 + vanilla ES5 console. New cross-cutting logic lives in small UMD helper modules (`errors.js`, `recentfilters.js`, `modalfocus.js`) loaded with `<script defer>` before `app.js` (no bundler, globals unchanged), each covered by `node --test` via a pytest wrapper. Templates only gain new elements/attributes; existing ids, attributes, ordering, and copy stay byte-identical except for locally-scoped content insertions reviewed as E3 insertions.

**Tech Stack:** FastAPI/Starlette, Jinja2, htmx 2.0.4, vanilla ES5 JavaScript, CSS custom properties, Node's built-in test runner (`node --test`, wrapped by pytest with `skipif` when Node is absent), pytest.

**Spec:** docs/superpowers/specs/2026-10-01-quality-hardening-design.md (Phase 3, §7)

## Global Constraints

From the spec's freeze contract; every task's requirements implicitly include this section.

- **INV-1 — Identical normal behavior.** For normal use, every observable output (HTTP status, body, headers except additive ones, files, DB rows, ordering, counts) is identical to today.
- **INV-2 — Additive-only UI.** No existing control moves, disappears, gains a required step, changes meaning, or changes its result. New affordances must be ignorable without cost (no mandatory fields, no new interrupts, no reordering of existing content).
- **INV-3 — Allowed behavior changes.** Behavior may differ only for cross-site requests, requests beyond a generous deadline, bodies above a generous cap, and infrastructure-outage visibility (plus the separately approved E1). This plan uses none of those; clone cancellation is a new capability required by the spec.
- **INV-4 — No runtime surface.** CI/format/type/coverage work changes no runtime behavior.
- **INV-5 — Exception register.** Any discovered unavoidable deviation is recorded in spec §11 with an explicit approval checkbox before it ships.
- **Additive-only rule (spec §7).** Add only things a user can ignore; nothing existing moves, reorders, or becomes required; new capabilities must leave current paths working unchanged.
- **HTML snapshot rule (spec §2, E3 pre-approved).** Phase 3 HTML snapshots may change only when the diff is pure insertion/addition: no existing bound value, attribute, order, or control may change. Each task's snapshot step must show that diff, and a reviewer must confirm insertion-only. JSON endpoint responses stay byte-exact (no snapshot tolerance for JSON).
- **No new npm dependencies, no bundler, no build step, no inline event handlers.** New helpers are UMD modules attached to `window` (`gitcorpusErrors`, `gitcorpusRecentFilters`, `gitcorpusModalFocus`) and loaded via `<script src="/static/<name>.js" defer></script>` in `base.html` before `app.js`; existing globals (`gitcorpusRowNav`, `htmx`) are untouched.
- **ES5 in `app.js`.** Keep `var`/IIFE style, double quotes, no arrow functions, no template literals, no `let`/`const`.
- **CSS uses only existing tokens** (`--gc-*`) and existing utility classes; htmx stays pinned at 2.0.4.
- **One commit per task, prefix `ux:`.** Stage only the files listed in the task.
- **Test commands.** Python: `pytest`. JS: `node --test tests/js/<name>.test.mjs`, always wrapped by a `tests/unit/test_<name>_js.py` pytest test using the `shutil.which("node") is None` skip pattern from `tests/unit/test_rownav_js.py`. Contract tests need `TEST_DATABASE_URL` pointing at a `_test` database; without it they skip, as today.
- **Phase dependencies (verified 2026-10-01):**
  - Phase 0 golden harness is **not present** (`tests/golden/` and `.github/workflows/` do not exist). Every snapshot step below states the fallback; executors must not fabricate golden files.
  - Phase 2 plan `docs/superpowers/plans/2026-10-01-adversarial-hardening.md` exists (written 2026-10-01) but is not yet executed. Its Task 6 declares `DELETE /runs/{run_id}/clone` → 200 with the progress payload or 404 `run_not_found`; Task 7 consumes that contract and still reads only `response.ok`.

Create `src/serve/static/errors.js`:

```javascript
(function (root, factory) {
  "use strict";
  if (typeof module === "object" && module.exports) {
    module.exports = factory();
  } else {
    root.gitcorpusErrors = factory();
  }
})(typeof self !== "undefined" ? self : this, function () {
  "use strict";

  function apiErrorText(status, body, fallback) {
    if (body && typeof body === "object") {
      if (typeof body.hint === "string" && body.hint) {
        return body.param ? body.param + ": " + body.hint : body.hint;
      }
      if (body.error === "timeout" && body.retry_after) {
        return "Timed out — retry in " + body.retry_after + "s";
      }
      if (body.error === "run_not_found") {
        return "Run not found";
      }
      if (typeof body.detail === "string" && body.detail) {
        return body.detail;
      }
      if (typeof body.error === "string" && body.error) {
        return body.error.replace(/_/g, " ");
      }
    }
    if (status) {
      return fallback || "Request failed";
    }
    return "Network error";
  }

  return { apiErrorText: apiErrorText };
});
```

```javascript
  function hideToast() {
    var toast = document.getElementById("toast");
    if (toast) {
      toast.hidden = true;
    }
    window.clearTimeout(toastTimer);
    toastTimer = null;
  }

  function showToast(message, retry) {
    var toast = document.getElementById("toast");
    if (!toast) {
      return;
    }
    toast.textContent = message;
    toast.hidden = false;
    window.clearTimeout(toastTimer);
    if (retry) {
      var retryButton = document.createElement("button");
      retryButton.type = "button";
      retryButton.className = "button";
      retryButton.setAttribute("data-toast-retry", "true");
      retryButton.textContent = "Retry";
      retryButton.addEventListener("click", function () {
        hideToast();
        retry();
      });
      var dismissButton = document.createElement("button");
      dismissButton.type = "button";
      dismissButton.className = "button ghost";
      dismissButton.setAttribute("data-toast-dismiss", "true");
      dismissButton.setAttribute("aria-label", "Dismiss message");
      dismissButton.textContent = "Dismiss";
      dismissButton.addEventListener("click", hideToast);
      toast.appendChild(retryButton);
      toast.appendChild(dismissButton);
      toastTimer = window.setTimeout(hideToast, 12000);
    } else {
      toastTimer = window.setTimeout(hideToast, 6000);
    }
  }
```

```javascript
(function (root, factory) {
  "use strict";
  if (typeof module === "object" && module.exports) {
    module.exports = factory();
  } else {
    root.gitcorpusRecentFilters = factory();
  }
})(typeof self !== "undefined" ? self : this, function () {
  "use strict";

  var MAX = 5;

  function parse(raw) {
    if (!raw) {
      return [];
    }
    var data;
    try {
      data = JSON.parse(raw);
    } catch (error) {
      return [];
    }
    if (!Array.isArray(data)) {
      return [];
    }
    var entries = [];
    for (var index = 0; index < data.length; index += 1) {
      var entry = data[index];
      if (!entry || typeof entry !== "object" || typeof entry.label !== "string") {
        continue;
      }
      if (!Array.isArray(entry.fields)) {
        continue;
      }
      var fields = [];
      for (var fieldIndex = 0; fieldIndex < entry.fields.length; fieldIndex += 1) {
        var field = entry.fields[fieldIndex];
        if (
          field &&
          typeof field.name === "string" &&
          typeof field.value === "string" &&
          field.value
        ) {
          fields.push({ name: field.name, value: field.value });
        }
      }
      if (fields.length) {
        entries.push({ label: entry.label, fields: fields });
      }
      if (entries.length >= MAX) {
        break;
      }
    }
    return entries;
  }

  function toQuery(fields) {
    var parts = [];
    for (var index = 0; index < fields.length; index += 1) {
      var field = fields[index];
      if (!field || !field.name || !field.value) {
        continue;
      }
      parts.push(encodeURIComponent(field.name) + "=" + encodeURIComponent(field.value));
    }
    return parts.join("&");
  }

  function label(fields) {
    for (var index = 0; index < fields.length; index += 1) {
      if (fields[index].name === "name" && fields[index].value) {
        return fields[index].value;
      }
    }
    for (var queryIndex = 0; queryIndex < fields.length; queryIndex += 1) {
      if (fields[queryIndex].name === "keywords" && fields[queryIndex].value) {
        return fields[queryIndex].value;
      }
    }
    return fields.length ? "Untitled filter" : "";
  }

  function push(entries, entry) {
    if (!entry || !entry.fields || !entry.fields.length) {
      return entries.slice(0, MAX);
    }
    var key = toQuery(entry.fields);
    if (!key) {
      return entries.slice(0, MAX);
    }
    var next = [entry];
    for (var index = 0; index < entries.length && next.length < MAX; index += 1) {
      var existing = entries[index];
      if (existing && existing.fields && toQuery(existing.fields) !== key) {
        next.push(existing);
      }
    }
    return next.slice(0, MAX);
  }

  return { MAX: MAX, parse: parse, toQuery: toQuery, label: label, push: push };
});
```

```javascript
          window.gitcorpusErrors.apiErrorText(status, body, "Cancel request failed"),
          function () {
            cancelClone(button);
          }
        );
      })
      .finally(function () {
        button.disabled = false;
      });
```

```javascript
  "use strict";
  if (typeof module === "object" && module.exports) {
    module.exports = factory();
  } else {
    root.gitcorpusModalFocus = factory();
  }
})(typeof self !== "undefined" ? self : this, function () {
  "use strict";

  function nextFocusIndex(current, length, backwards) {
    if (length <= 0) {
      return -1;
    }
    if (current < 0) {
      return backwards ? length - 1 : 0;
    }
    if (backwards) {
      return current <= 0 ? length - 1 : current - 1;
    }
    return current >= length - 1 ? 0 : current + 1;
  }

  return { nextFocusIndex: nextFocusIndex };
});
```

```javascript
  var activeModal = null;
  var restoreFocusTo = null;

  function focusableElements(modal) {
    var selector =
      'a[href], button:not([disabled]), input:not([disabled]), select:not([disabled]), textarea:not([disabled]), [tabindex]:not([tabindex="-1"])';
    return Array.prototype.slice.call(modal.querySelectorAll(selector)).filter(function (element) {
      return element.getClientRects().length > 0;
    });
  }

  function openModal(id) {
    var modal = document.getElementById(id);
    if (!modal) {
      return;
    }
    if (activeModal && activeModal !== modal) {
      closeModal(activeModal.id);
    }
    restoreFocusTo =
      document.activeElement && document.activeElement !== document.body
        ? document.activeElement
        : null;
    activeModal = modal;
    modal.hidden = false;
    var focusable = focusableElements(modal);
    if (focusable.length) {
      focusable[0].focus();
    }
  }

  function closeModal(id) {
    var modal = document.getElementById(id);
    if (!modal) {
      return;
    }
    modal.hidden = true;
    if (activeModal === modal) {
      activeModal = null;
    }
    if (restoreFocusTo && typeof restoreFocusTo.focus === "function") {
      restoreFocusTo.focus();
    }
    restoreFocusTo = null;
  }

  function toggleShortcutsModal() {
    var modal = document.getElementById("shortcuts-modal");
    if (!modal) {
      return;
    }
    if (modal.hidden) {
      openModal("shortcuts-modal");
    } else {
      closeModal("shortcuts-modal");
    }
  }

  function closeOpenModal() {
    var open = document.querySelector(".modal:not([hidden])");
    if (open) {
      closeModal(open.id);
      return true;
    }
    return false;
  }

  function trapTab(event) {
    if (!activeModal) {
      return false;
    }
    var focusable = focusableElements(activeModal);
    if (!focusable.length) {
      event.preventDefault();
      return true;
    }
    var current = focusable.indexOf(document.activeElement);
    var next = window.gitcorpusModalFocus.nextFocusIndex(
      current,
      focusable.length,
      event.shiftKey
    );
    event.preventDefault();
    focusable[next].focus();
    return true;
  }
```
